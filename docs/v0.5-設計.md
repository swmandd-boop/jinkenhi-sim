段階2の実装上の判断（設計との差分）：

- 軸域は基準3:1のサービスで 4.0:1〜1.0:1（rmax=基準+1・rmin=1・基準線=基準）。基準の無い通所は
  現在比率まわりに自動でとり基準線を引かない。
- グラフ点は「配置比率 × 職員1人あたり給与費 B(R)」。B(R)=給与原資÷職員数(R)で、職員数(R)=
  核職員×(users/R)/coreN ＋ その他職員（固定）。曲線・比率↔ロスター変換は engine の
  bAtRatio／staffNAtRatio／scaleCoreToRatio に置き、UI では計算しない（表示専用の再計算の禁止）。
- 「基準ちょうど」警告（§6・slackN）は全職種が基準ちょうどのときに出る。配置比率ドラッグは
  その他職員を動かさないため、その他が基準ちょうどのままだと薄→厚に動かしても警告は残る
  （＝固定職種に余裕がないという診断として正しい）。全職種を基準超にすると外れる。
- 段階2で人軸ベースの縦補助線（基準の単純合計・職種別基準最小・配置下限）はグラフから外し、
  基準線（配置比率＝基準）と賃金下限に置き換えた。人数ベースの下限は §5/§6 の本文側で表示継続。
- INV-26 は実DOM（つまみ値とグラフ点のcx）で突合するため ui.test.mjs に置く。

## 背景

v0.4 を実機で確認した結果、次の問題が出た。

- グラフのドラッグが職種表の人数を一律に書き換えるため、基準1.0の施設長が1.8人になる

  人数だけ精緻でも分析としては半端になる

水田さんの判断：**介護・看護の3:1に対して介護職員の適正配置を重点的に見せる設計にする。**
職種別の細かい内訳は不要。

## 1. 職種表を3行にする

10行から3行へ。各行に正規・非正規・派遣の3列。

```
職種          基準    正規   非正規   派遣    合計
介護職員      22.6    ○○     ○○     ○○     ○○
看護職員       3.0    ○○     ○○     ○○     ○○
その他職員     5.1    ○○     ○○     ○○     ○○
```

- **介護職員・看護職員**は3:1判定の対象。看護職員は段階配置（入所者30以下1／30超50以下2／
  50超130以下3／130超は50ごとに+1）の判定も残す。看護不足は指定権者の指導対象になるため
- **その他職員**は原資を食う分としてまとめる。基準は施設長1・医師0.1・生活相談員1・
  機能訓練指導員1・介護支援専門員1・管理栄養士1の合計を自動計算し、内訳は注記で示す
- 基準常勤換算は定員・稼働率から自動計算（v0.4 と同じ）
- **正規・非正規・派遣の初期値は、基準と同じ値を正規に入れる**（非正規・派遣は0）。
  そこから施設の実情に応じて手入力してもらう

## 2. 派遣職員の扱い

社会福祉法人会計基準では**派遣職員費は人件費の中科目**である。
したがって給与原資の配分対象に含まれ、配置基準の判定にも算入される。

**STEP2の入力を1つ増やす。**

```
年間人件費総額（法定福利費込み）    ○○ 万円
　うち派遣職員費                    ○○ 万円   ← 内数
```

正規・非正規を金額で分けて尋ねる必要はない。人数は職種表で入るため、
金額側は「職員分」と「派遣分」の2つで足りる。

**計算**

```
職員給与原資 ＝（人件費総額 − 派遣職員費）÷（1 + 法定福利費率）
派遣費用     ＝ 派遣職員費（法定福利費の割り戻しをしない。派遣会社が負担するため）
```

**分子と分母を必ず揃えること。** 派遣費が分子に入っているのに派遣の人数を分母から
外すと、1人あたりが実態より高く出る。80床で派遣5人なら分母が53人か48人かで
1割の差が生じ、賃金水準を読み違える。

## 3. 横軸を配置比率にする（バーとグラフを統一）

**職員数バーは残す。** ただし目盛りを配置比率に変え、グラフの横軸と一致させる。

```
バー・グラフ横軸：介護・看護職員 対 入所者　4.0 : 1 〜 1.0 : 1
```

- 4.0:1 は基準3:1を下回る側。**基準割れの領域も見える**ようにする
- 3.0:1 の位置に基準線を引き、そこから左（薄い側）が基準違反であることを示す
- 1.0:1 は入所者と同数。実務上の上限として十分

これによりバーとグラフが同じ目盛りになり、v0.4 で起きた
「バーは右端なのにグラフの点は中途半端な位置」という不一致が構造的に消える。

**ドラッグの反映先**

配置比率を動かすので、増減は介護職員・看護職員に反映される。
**その他職員は動かない。**「基準1.0の施設長が1.8人になる」問題は起きない。

介護と看護の配分は、現在の構成比を保って按分する。

## 4. 縦軸に2本の曲線を引く

同じ縦軸（万円）に2本。

```
A：1人あたり給与費        ＝ 人件費総額 ÷（正規＋非正規＋派遣）
　　分子・分母とも派遣を含む。決算書・経営概況調査と同じ土俵の経営指標

B：職員1人あたり給与費（額面） ＝ 職員給与原資 ÷（正規＋非正規）
　　派遣を分子・分母から除く。求人票・賃金センサスと同じ土俵の賃金水準
　　正規と非正規で金額を分けない（第9節）
```

**2本の間隔について（設計時に一度誤った箇所）。**
当初「間隔＝派遣の影響量」と考えたが誤り。AとBは基準が違うため、
派遣がゼロでも一致しない。

```
派遣0のとき　A ÷ B ＝ 1 + 法定福利費率　（例：16.5% なら常に 1.165 倍）
```

実測（特養80床・人件費24,800万・派遣0）：3.0:1 で A=807.8万／B=693.4万（差114.4万）。
この差はすべて事業主負担であって、派遣とは無関係である。

したがって2本の間隔は「事業主負担＋派遣の効果」の合成であり、
派遣の影響量としては読めない。**そう説明しないこと。**

- **賃金下限の線はBに対して引く。** 守るべきは職員本人の賃金水準であるため
- Aは事業主負担込み、Bは額面。凡例でこの違いを必ず明示する
- 派遣の影響は、次の別指標で示すほうが正確
  - 派遣1人あたり費用 ＝ 派遣職員費 ÷ 派遣人数
  - 職員1人あたり人件費 ＝（人件費総額 − 派遣職員費）÷ 職員数
  この2つを並べれば、派遣が自前より高いか安いかが直接わかる

## 5. 診断の中心

**「この原資なら何:1まで手厚くできるか」**を主たる答えにする。

計算例（特養80床・稼働96%・入所者76.8人・人件費24,800万・法定福利費16.5%・派遣0）

| 配置比率 | 介護・看護 | 合計 | 平均年収(B) |
|---|---|---|---|
| 3.0 : 1（基準ちょうど） | 25.6 | 30.7 | 693.4万 |
| 2.5 : 1 | 30.7 | 35.8 | 594.3万 |
| 2.0 : 1 | 38.4 | 43.5 | 489.4万 |
| 1.8 : 1 | 42.7 | 47.8 | 445.7万 |
| **1.6 : 1** | 48.0 | 53.1 | **400.9万** |

賃金下限400万を守れる限界は **1.60 : 1**。

表示する一文の例：
> この原資なら 1.60 : 1 まで手厚くできます。それ以上は平均年収が 400 万円を割ります。

**閾値は発明しない。** 基準3:1は法令、賃金下限は入力値。いずれもこちらが決めた値ではない。

## 9. 非正規の賃金水準（係数70%）は削除する

v0.4 では「正規の平均年収 × 70%」で非正規の年収を出していたが、**削除する。**

人件費総額の中に正規・非正規の給与費がいずれも含まれているため、
常勤換算職員数が正しければ 1人あたり給与費は割り算で出る。
未検証の係数を挟む必要がない。

```
職員1人あたり給与費 ＝（人件費総額 − 派遣職員費）÷（正規＋非正規）
派遣1人あたり費用   ＝ 派遣職員費 ÷ 派遣
```

**正規と非正規を金額で分けない。** 分けるには内訳を尋ねるしかなく、入力が増える。

正規・非正規を人数で分ける意味は残る。配置基準の判定には両方が算入され、
正規比率そのものが人事考課・賃金制度の議論で使う指標になるため。
金額の按分に使わない、というだけである。

これに伴い、第4節Bの「正規・非正規の平均年収」は
**「職員1人あたり給与費（額面）」**に読み替える。
