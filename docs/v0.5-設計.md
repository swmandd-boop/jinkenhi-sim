## 1. 職種表を3行にする

10行から3行へ。各行に正規・非正規・派遣の3列。

```
職種          基準    正規   非正規   派遣    合計
介護職員      22.6    ○○     ○○     ○○     ○○
看護職員       3.0    ○○     ○○     ○○     ○○
その他職員     5.1    ○○     ○○     ○○     ○○
```

- **介護職員・看護職員**は3:1判定の対象。看護職員は段階配置（入所者30以下1／30超50以下2／
  50超130以下3／130超は50ごとに+1）の判定も残す。看護不足は指定権者の指導対象になるため
- **その他職員**は原資を食う分としてまとめる。基準は施設長1・医師0.1・生活相談員1・
  機能訓練指導員1・介護支援専門員1・管理栄養士1の合計を自動計算し、内訳は注記で示す
- 基準常勤換算は定員・稼働率から自動計算（v0.4 と同じ）
- **正規・非正規・派遣の初期値は、基準と同じ値を正規に入れる**（非正規・派遣は0）。
  そこから施設の実情に応じて手入力してもらう

## 2. 派遣職員の扱い

社会福祉法人会計基準では**派遣職員費は人件費の中科目**である。
したがって給与原資の配分対象に含まれ、配置基準の判定にも算入される。

**STEP2の入力を1つ増やす。**

```
年間人件費総額（法定福利費込み）    ○○ 万円
　うち派遣職員費                    ○○ 万円   ← 内数
```

正規・非正規を金額で分けて尋ねる必要はない。人数は職種表で入るため、
金額側は「職員分」と「派遣分」の2つで足りる。

**計算**

```
職員給与原資 ＝（人件費総額 − 派遣職員費）÷（1 + 法定福利費率）
派遣費用     ＝ 派遣職員費（法定福利費の割り戻しをしない。派遣会社が負担するため）
```

**分子と分母を必ず揃えること。** 派遣費が分子に入っているのに派遣の人数を分母から
外すと、1人あたりが実態より高く出る。80床で派遣5人なら分母が53人か48人かで
1割の差が生じ、賃金水準を読み違える。

## 3. 横軸を人数空間（常勤換算数）にし、配置比率を併記する（バーとグラフを統一）

> 改訂（2026-07-28）。段階2で一度「横軸＝配置比率」にしたが、比率を横軸にすると
> **等原資曲線 給与原資÷n の双曲線が視覚的に失われる**ことが実測で判明した。比率 R と
> 職員数 n はほぼ反比例（n ≒ 入所者数÷R ＋ その他職員）のため、原資÷n を R に対して描くと
> 反比例が打ち消され、その他職員が0なら完全な直線になる。よって横軸は人数空間に戻す。
>
> 実測（画面上の傾きの左端付近/右端付近の比）：人数軸 7.02倍（はっきり曲がる）／
> 配置比率軸 0.75倍（ほぼ直線）／その他0のとき 比率軸 1.00倍（完全直線）・人数軸 9.33倍。
>
> ※この実測は指標がまだ B（給与原資÷n）だった時点のもの。**その後 決定②で A（人件費総額÷n）に
> 一本化した**が、どちらも n の反比例なので「人数軸なら曲がる／比率軸なら直線化する」という
> 結論は変わらない。以降の本文で「給与原資÷n」とあるのは当時の記録。

**職員数バーもグラフ横軸も人数空間（常勤換算の職員数 n）にする。** 曲線は 人件費総額÷n の
双曲線として描く（当初は給与原資÷n としたが、決定②で指標をAに一本化）。段階2で作った「つまみ位置とグラフ点を同じ割合 f から算出する」構造は維持し、
f を人数空間で定義する（→ INV-26 は人数空間で一致）。

**横目盛りは配置比率と常勤換算数を上下2段で併記する。**

```
上段：4.0:1 / 3.5:1 / 3.0:1 / 2.5:1 / 2.0:1 / 1.5:1 / 1.2:1 / 1.0:1
下段：それぞれに対応する常勤換算数（職員数 n）
```

- 目盛り間隔が不均等になるのは**正しい**。手厚くするほど1段階のコスト（職員数の増分）が
  増えることが、間隔の詰まり方（薄い側で詰まり、手厚い側で広がる）で見える
- 表示範囲は 4.0:1 相当 〜 1.0:1 相当の職員数。基準割れ側（4.0:1〜3.0:1）も見える
- 3.0:1 に対応する職員数の位置に基準線を引き、そこから左（薄い側＝職員少）を淡く塗る
- 薄い端で目盛りラベルが詰まって重なる場合は、左から貪欲に最小間隔をあけて間引く
  （基準線と両端は残す）

これによりバーとグラフが同じ人数目盛りになり、v0.4 で起きた
「バーは右端なのにグラフの点は中途半端な位置」という不一致が構造的に消える。

**ドラッグの反映先**

増減は介護職員・看護職員に反映される。**その他職員は動かない。**
「基準1.0の施設長が1.8人になる」問題は起きない。介護と看護の配分は、現在の構成比を保って按分する。
（人数軸の目標職員数 n はエンジンで配置比率 R＝a/(n−その他職員) に戻してから核だけ按分する。）

## 4. 縦軸は A の1本に一本化する（B は削除・2曲線は実装しない）

> **2026-07-28 決定②：指標を A に一本化し、B を削除する。** B（職員給与原資÷職員（正規＋非正規））を
> 採用すると、派遣がいる施設で「バー（例 70.9人）＝正規＋非正規＋派遣」と「グラフ（例 68.6人）＝
> 正規＋非正規」が食い違って見える。計算はどちらも正しいが、同じ「人」の単位で違う母集団を並べると
> プログラムの誤りに見える。これを避けるため、**画面の指標・軸・人数をすべて A と職員数（fteAll＝
> 正規＋非正規＋派遣）に統一する。**
>
> - **1人あたり給与費（A）＝ 人件費総額 ÷（正規＋非正規＋派遣）。** 分子に派遣費・事業主負担を含むので
>   分母にも派遣を含めて揃える。派遣0では自動的に正規＋非正規になり、場合分けが不要（→ INV-22/23）。
> - **グラフ縦軸＝A、横軸の職員数＝fteAll。** バーとグラフの人数が一致し、食い違いが構造的に消える（→ INV-04/UI-17）。
> - **賃金下限は額面のまま入力**（求人票と同じ土俵）し、比較のときだけ内部で **×(1+法定福利費率)** して
>   A軸上の位置に線を引く。線のラベルは「賃金下限 440万円（事業主負担込み 512.6万円）」と併記する（→ UI-18）。
> - **派遣1人あたり費用（派遣職員費÷派遣人数）は残す**が、「年収」ではなく「費用」であることを明示する。
> - B（額面 職員1人あたり）と、それに紐づく月例給・賞与月数入力は削除した。
>
> **2026-07-28 決定①：2本の曲線は実装しない。** 配置比率を横軸にすると双曲線が直線化し（§3改訂）、
> A・B の2本を重ねるとグラフが読みにくくなるため、グラフには2本目の曲線も推移の点も引かない。
> トレードオフの両面は §7 推移の下の「同じジレンマの両面」（5年後の2枚のカード）で数値として示す。
> 以下は当初案（AとBの2曲線）の記録として残す。

同じ縦軸（万円）に2本。

```
A：1人あたり給与費        ＝ 人件費総額 ÷（正規＋非正規＋派遣）
　　分子・分母とも派遣を含む。決算書・経営概況調査と同じ土俵の経営指標

B：職員1人あたり給与費（額面） ＝ 職員給与原資 ÷（正規＋非正規）
　　派遣を分子・分母から除く。求人票・賃金センサスと同じ土俵の賃金水準
　　正規と非正規で金額を分けない（第9節）
```

**2本の間隔について（設計時に一度誤った箇所）。**
当初「間隔＝派遣の影響量」と考えたが誤り。AとBは基準が違うため、
派遣がゼロでも一致しない。

```
派遣0のとき　A ÷ B ＝ 1 + 法定福利費率　（例：16.5% なら常に 1.165 倍）
```

実測（特養80床・人件費24,800万・派遣0）：3.0:1 で A=807.8万／B=693.4万（差114.4万）。
この差はすべて事業主負担であって、派遣とは無関係である。

したがって2本の間隔は「事業主負担＋派遣の効果」の合成であり、
派遣の影響量としては読めない。**そう説明しないこと。**

- **賃金下限の線はBに対して引く。** 守るべきは職員本人の賃金水準であるため
- Aは事業主負担込み、Bは額面。凡例でこの違いを必ず明示する
- 派遣の影響は、次の別指標で示すほうが正確
  - 派遣1人あたり費用 ＝ 派遣職員費 ÷ 派遣人数
  - 職員1人あたり人件費 ＝（人件費総額 − 派遣職員費）÷ 職員数
  この2つを並べれば、派遣が自前より高いか安いかが直接わかる

## 9. 非正規の賃金水準（係数70%）は削除する

v0.4 では「正規の平均年収 × 70%」で非正規の年収を出していたが、**削除する。**

人件費総額の中に正規・非正規の給与費がいずれも含まれているため、
常勤換算職員数が正しければ 1人あたり給与費は割り算で出る。
未検証の係数を挟む必要がない。

```
1人あたり給与費（A） ＝ 人件費総額 ÷（正規＋非正規＋派遣）   ← v0.5 決定②で A に一本化
派遣1人あたり費用     ＝ 派遣職員費 ÷ 派遣人数（賃金ではなく費用）
```

**正規と非正規を金額で分けない。** 分けるには内訳を尋ねるしかなく、入力が増える。

正規・非正規を人数で分ける意味は残る。配置基準の判定には両方が算入され、
正規比率そのものが人事考課・賃金制度の議論で使う指標になるため。
金額の按分に使わない、というだけである。

> **2026-07-28 追記（決定②）。** 当初は「職員1人あたり給与費（額面）＝（人件費総額−派遣費）÷（正規＋非正規）」
> ＝ B を額面指標として残す想定だったが、B（分母＝正規＋非正規）と 配置・グラフの職員数（分母＝
> 正規＋非正規＋派遣）が食い違って見えるため、**B は削除し、A（人件費総額÷職員数・派遣込み・事業主
> 負担込み）に一本化した。** B に紐づく月例給・賞与月数入力も削除。賃金下限（額面）は A軸で比較するとき
> ×(1+法定福利費率) して線を引く（第4節）。

## 11. 案B：横軸は職員数に統一し、配置比率は基準のあるサービスでのみ併記（2026-07-28 実装）

**通所介護には対利用者の比率基準が存在しない。** 介護職員は「利用者15人まで1以上、15人を超える
部分は5人ごとに1を加えた数」を提供時間帯を通じて配置する規定で、常勤換算は営業日数と提供時間に
左右される。特養の3:1のような比率の形をしていない。にもかかわらず横軸を比率で刻んでいたため、
15.4:1 等の意味のない目盛りが出て、基準線も引けない（凡例だけ残る）状態だった。

### 各サービスで比率基準が成立するか

| サービス | 法令上の人員基準 | 比率基準 | 画面の扱い |
|---|---|---|---|
| 特養（従来型） | 介護・看護の総数が入所者3:1以上＋看護は段階配置 | **成立** | 比率を併記・基準線3:1 |
| ユニット型 | 同上3:1＋ユニット常時配置 | **成立**（3:1は必要条件） | 同上 |
| 老健 | 看護・介護の総数が3:1以上。**うち看護2/7・介護5/7は「標準」（目安）** | **成立** | 同上（下記の注記つき） |
| 通所介護 | 利用者15人まで1、超過5人ごとに+1（提供時間帯を通じて）＋看護1以上 | **不成立** | **比率を出さない** |

### 実装

- 横軸は全サービスとも職員数（fteAll）。比率基準の有無は `hasRatioStd(c)` で判定する。
- **比率基準なし（通所）で出さないもの**：上段の比率目盛り／基準線／凡例の「基準線」／
  比率スライダーのラベル（「職員数 ◯人」を主表示）／chartnote の比率・基準割れ文言／
  両面カードの比率行（減る人数で表示）／グラフ点ラベルの比率／**指標バーの比率セル**／
  **書き出しテキストの配置比率行**。
  凡例の帯の文言も「基準内かつ賃金下限を満たす区間」→「賃金下限を満たす区間」に変える。
- **通所の軸域**は「**核（介護・看護）の基準を 0.75倍〜3倍**にした職員数」に固定する
  （＝`核std×0.75＋その他std` 〜 `核std×3＋その他std`）。2026-07-28 に ×0.85〜×2.0 から拡張。
  ★当初案の nMinComp（今の構成で基準を満たす最小）はアンカーに使えない。nMinComp は
  `max(std/行合計)` で現在の職種構成に依存するため、核だけを動かすドラッグで値が変わり、
  **軸が動いてしまう**（「軸域がドラッグで動かないこと」と両立しない）。stdN は定員・稼働率だけで
  決まる法令由来の値でドラッグ不変なので、こちらをアンカーにする（閾値の発明ではない）。
- 充足判定は従来どおり職種別基準（15人まで1・超過5人ごとに+1）で行う。変更なし。
- 老健の注記を caveat に追加：「うち看護2/7・介護5/7は標準（目安）で、行別判定はこれに基づく」。
  合計3:1を満たしていても配分が標準と異なると行別で不足と出ることがある旨を明示。

### 指標バー・書き出しの比率も出さない（2026-07-28 水田さん判断で追補）

当初は指標バーの比率セルを記述統計として残していたが、**通所では出さない**ことに決定した。理由：

1. グラフから比率を消したのは「通所介護に対利用者比率の基準が存在しない」ため。**同じ理由が
   指標バーにも当てはまる。** 基準がないのに数字だけ出すと、見た人は比較先を探すが比べる相手がない。
2. 他サービスでは同じ位置の同じセルが**基準との比較**（「基準 3:1 の 1.00 倍の手厚さ」）に使われる。
   同じ場所の同じセルがサービスによって意味を変えるのは、**「同じ名前で違うものを指す」問題と同じ型**。

同じ理由から、**書き出しテキスト（相談用）の配置比率行も比率基準のあるサービスに限る**
（数字だけが文脈から切り離されて独り歩きするのを防ぐ）。AXB-01 で両方を固定。

### テスト

AXB-01（通所で比率目盛り・基準線・凡例・比率スライダーを出さない）／AXB-02（通所の軸域が
ドラッグで動かない＝目盛りとアンカーが不変・同じつまみ位置で職員数が再現）／
AXB-03（特養・ユニット・老健で従来表示を維持）。

## 14. 通所の軸域を特養系と同じ幅に広げる（2026-07-28）

### 直した問題

軸域が `stdN×0.85〜×2.0` だった。**左端が基準の0.85倍**しかなく、基準を大きく割る領域が
見えない。0.85 という係数にも根拠がなかった。特養系は 4.0:1〜1.0:1 で基準3:1を大きく割る側まで
見えるため、通所だけ検討の幅が狭かった。

**判断の根拠（水田さん）**：基準ちょうどまでしか見えないと、そこで検討が止まる。
「これ以上薄くできないなら、賃金を上げるには稼働率か収入を動かすしかない」という判断に
つなげるため、基準を割る領域も見える必要がある。

### 採用した範囲と、その導出（係数を発明していないこと）

比率基準のあるサービスの軸は 左端 R＝基準+1／右端 R＝1。核は `core(R)＝利用者÷R` なので、

```
左端の核 ＝ 基準/(基準+1) 倍 ＝ 3/(3+1) ＝ 0.75倍
右端の核 ＝ 基準/1 倍       ＝ 3倍
```

**この 0.75〜3 は基準3:1のサービスで共通**（実測で特養・ユニット・老健とも一致）。
通所も同じ核倍率にすれば、基準を割る側も同じ深さ（25%薄い）まで見える。
→ `nmin = 核std×0.75 ＋ その他std`、`nmax = 核std×3 ＋ その他std`。

**stdN に直接倍率を掛けない理由**：その他職員まで一緒に増減させることになる。
ドラッグは核しか動かさない（その他は固定）ので、軸の端も核の増減で定義するのが対応する。
実測の stdN 倍率は 特養0.79〜2.67／ユニット0.73〜2.47／老健0.79〜2.66／通所0.83〜2.36 と
サービスごとに違うが、これは その他職員の比率が違うためで、**核倍率で揃えるのが正しい対応**。

### 制約の充足

| 制約 | 結果 |
|---|---|
| ゼロ除算が再発しないこと | 左端でも核は基準の**0.75倍（>0）**。端点を連続80回踏んでも核0・Infinity・NaN なし |
| 軸域がドラッグで動かないこと | 核std・その他std はどちらも定員・稼働率だけで決まりドラッグ不変。目盛り文字列の一致で確認 |
| 特養系の表示は変更しない | 軸（24.3〜81.9／29.2〜98.2）・比率目盛り7点・基準線1本とも変更なし |

実測（通所・定員35/稼働88%）：軸 6.72〜19.10（旧 6.88〜16.20）。左端の核 4.13人＝基準5.5人の75%。
基準の単純合計 8.1人を左端が下回り、基準割れの領域が見えるようになった。

テスト：**AXB-04**（左端が基準の単純合計を下回る／左端の核が基準の0.75倍かつ>0／右端が3倍／
端点を連続80回踏んでも異常なし／特養系も核0.75〜3倍で一致）。変更前のコミットで落ちることを確認済み。
AXB-02（軸不変）・AXB-03（特養系不変）・ZERO-01（端点連続）は維持。
