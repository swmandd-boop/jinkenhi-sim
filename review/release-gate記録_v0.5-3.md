## H1【最重要・P2】通所で「基準を割る配置」が緑の帯（＝満たしている区間）に含まれている

**今回の変更（軸を基準より左へ拡張＋基準マーカー追加）によって顕在化した表示上の矛盾。**

### 実測

| サービス | 基準マーカーの位置 x | 緑帯（太実線）の左端 x | 帯が基準より左へ伸びるか |
|---|---|---|---|
| 通所介護 | 125.6 | **64.0（プロット左端）** | **★はい** |
| 特養 | 125.6 | 128.6 | いいえ（基準線で止まる） |

さらに、通所で左端（職員 6.7人＝基準 8.1人を割る位置）に置くと、**同じ画面が別のことを言う**：

- 充足判定パネル：「**職種別の基準を下回っています**」
- グラフ：その位置は**緑の帯の内側**（凡例は「賃金下限を満たす区間」）

### 原因（コード）

`renderChart` の帯の条件が、比率基準の無いサービスでは**基準による切り出しを一切していない**。

```js
var okBand = seg(function(R, y){
  return (!nx.ax || !nx.ax.base || (R != null && R <= nx.ax.base + 1e-9))   // ← 通所は nx.ax が null で無条件 true
         && (!(c.atgt > 0) || y >= c.floorA - 1e-9);                        // 賃金下限だけで切っている
});
```

特養系は `R <= 基準` で切るため基準線で帯が止まるが、**通所は賃金下限だけで帯を引く**。
軸が基準の左まで広がった今、その差が「基準割れでも緑」という形で見えるようになった。

### 観点①への回答

**現状は「誤解を招かないか」ではなく、実際に誤読される表示になっている。**
「基準を割る領域も見せる」という意図は正しいが、**見せ方が「そこも合格」になっている**。
基準割れの配置を提案しているように読める。

### 修正案（2つ・いずれも小さい）

1. **帯を基準で切る（推奨）**：比率基準の無いサービスでは `n >= nbase`（基準の単純合計以上）を
   帯の条件に加える。特養系と対称になり、凡例も「基準内かつ賃金下限を満たす区間」に統一できる。
2. **帯は変えず、凡例と説明で限定する**：通所の凡例を「賃金下限を満たす区間（基準充足は別途判定）」に
   するなど。ただし**画面内の矛盾は残る**ため、1 を推奨する。

- あわせて：現在の通所の凡例は「賃金下限を満たす区間」で**基準に触れていない**。1 を採れば特養系と同文にできる。
- リスク残：修正しない場合、「基準を割ってもよい」と読まれる余地が残る。**開示（充足判定パネル）で
  打ち消しているとは言い切れない**（同じ画面で逆の合図を出しているため）。
