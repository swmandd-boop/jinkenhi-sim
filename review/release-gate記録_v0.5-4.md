## I1【P2】帯の基準判定が「合計人数」ベースで、ツール自身が否定している判定方法と同じ

### 実測（通所介護・定員35/稼働88%）

基準：介護 4.4／看護 1.1／その他 2.6（合計 8.1）
実配置：**介護 2.0（基準割れ）／看護 1.1／その他 6.0（基準超）** → 合計 **9.1**（基準合計 8.1 以上）

- 充足判定パネル：「**職種別の基準を下回っています**」
- グラフ：点 x=170.3 は帯 128.6〜234.8 の**内側**（＝成立して見える）

**H1 と同型の矛盾が、別の経路（職種構成の偏り）で残っている。**

### 原因

今回加えた帯の条件が、比率基準の無いサービスでは `n >= nbase`＝**合計人数 ≧ 基準の単純合計**である。
ところが**ツール自身が caveat でこの判定方法を明確に否定している**：

> 3:1などの配置基準は**職種別の要件**です。事務や調理を厚くすれば合計人数を満たしたまま
> 介護・看護が基準を割るため、**合計の下限だけでは判定できません**。

帯は「ここなら成立する」を示すのに、その判定に**ツールが「使えない」と書いている物差し**を使っている。

### 特養系も同型（ただし今回の変更以前からの性質）

特養の帯条件は `R <= 基準`＝**核（介護・看護）の比率のみ**で、その他職員の不足を見ていない。
実測：その他を 1.0（基準5.1割れ）にすると充足判定は「下回っています」になるが、
帯の条件自体はその他を評価していない（この例では点がたまたま帯の左外に出たため矛盾は表面化せず）。
**構造としては通所と同じ弱さがある。**

### 修正案

1. **帯の左端を `nMinComp` にする（推奨・全サービス共通）**。
   engine に既にある「**いまの職種構成のまま人数を増減させたとき、全職種が基準を満たす最小の合計**」。
   実測：上記の偏った構成で `nMinComp = 20.0` となり、現在地 9.1 は帯の外＝**充足判定と一致**する。
   比率基準のあるサービスでは `R <= 基準` を **AND で残す**（比率は必要条件のため）。
   - 副次効果：帯の左端が職種構成に応じて動く。軸は固定のままなので、
     「構成を直せば成立範囲が広がる」ことが視覚的に伝わる（現在は `nmin-note` の文章のみ）。
2. **現状維持とし、帯の意味を限定する**。凡例を「**合計人数と賃金の目安**（職種別の充足は判定欄で確認）」に
   改め、chartnote にも同旨を書く。実装は軽いが、**「基準内」と名乗る帯が職種別基準を見ていない**
   ねじれは残る。

- リスク残：修正しない場合、**職種構成が偏った施設で「グラフは成立、判定は未達」が再発**する。
  ただし充足判定パネルは常に正しく出ており、`nmin-note`（「いまの構成のままだと合計◯人必要」）も
  出ているため、**開示は多重にある**。P0/P1ではない。

## STAGE 2 重点観点

### 観点① 帯を基準で切ったことで情報が減っていないか … 🟡

**基準割れ領域の情報は減っていない**（実測）：

| 要素 | 状態 |
|---|---|
| 灰色の破線（等・人件費総額の曲線） | **全域 x=64.0〜618.0 に描画**（基準割れ側にも曲線が残る） |
| 基準割れ領域の淡い塗り | **あり**（x=64 から幅61.6＝基準マーカーまで） |
| 基準マーカーとラベル | 「基準 8.1人」／特養は「基準 3 : 1」 |
| 緑の帯 | 基準の右側からのみ |

→ 「**薄くするとどこまで賃金が上がるかは見える（破線）が、そこは成立範囲ではない（帯なし・塗りあり）**」
という読み分けが成立している。**軸を広げた目的（基準割れ側も見せて稼働率・収入の検討につなげる）は
維持されており、情報は減っていない。**

- 指摘J（P3）：破線・塗り・帯の3要素で意味を分けているが、**凡例には破線と塗りの説明がない**
  （凡例は帯・賃金下限・基準線・いまの置き方の4項目）。
  「破線＝同じ人件費で取り得る組み合わせ」「塗り＝基準を下回る領域」を凡例に足すと読み分けが明示的になる。
- **ただし I1 のとおり、帯の「基準内」の中身が職種別要件と一致していない。**
  情報量の問題ではなく判定の中身の問題として、上記 I1 を参照。

### 観点② 凡例の語の使い分けが伝わるか … 🟢

実測（全4サービス）：

| サービス | 帯 | 基準線 |
|---|---|---|
| 通所介護 | 基準内かつ賃金下限を満たす区間 | **基準線（人数）** |
| 特養／ユニット／老健 | 基準内かつ賃金下限を満たす区間 | **基準線（配置比率）** |

- **同じ意味の要素（帯）は全サービス同一文言**、**違う意味の要素（基準線）は括弧で区別**という
  整理が実装どおりに効いている。AXB-09 で固定済み。
- グラフ内のラベル（「基準 8.1人」「基準 3 : 1」）とも符合し、凡例だけを見ても
  「人数の基準か、比率の基準か」が分かる。
- 第3回の指摘E（同じ語が2つを指す）は**解消**。
- リスク残：低。
