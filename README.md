# SWMD 人件費トレードオフ・シミュレーター v0.3

福祉施設の人件費原資に対して、職員配置（常勤換算）と賃金水準が同時には決められないことを、
サービス種別の人員配置基準と突き合わせて確認するツール。

## このリポジトリの構成

```
jinkenhi-sim.html          本体。単一HTML・外部通信なし。これをそのまま公開する
engine.mjs                 自動生成。編集しない（jinkenhi-sim.html から抜き出したもの）
tools/extract-engine.mjs   本体の ENGINE 区間を engine.mjs に抜き出す
tools/dump-screen.mjs      画面の全表示値をテキストに書き出す（adversarial-review モード2用）
tests/helpers.mjs          テスト用の入力生成とUI操作の再現
tests/invariants.test.mjs  計算層の不変条件 14 件
tests/ui.test.mjs          画面の矛盾検出 5 件（実バグの回帰テストを含む）
tests/explore.mjs          ランダム入力の探索テスト（既定 10,000 ケース）
review/screen-dump.txt     自動生成。レビュー材料
```

## 設計の約束（守らないとテストが機能しなくなる）

本体HTMLは2つの区間に分かれている。

- `/* ===== SWMD-ENGINE:BEGIN ===== */` 〜 `:END`
  **DOMに触れない純粋な計算層。** 入力オブジェクトを受け取り、画面に出す全数値を返す。
  この区間に `document` / `window` / `getElementById` を書いてはいけない。
  `tools/extract-engine.mjs` がガードしており、混入すると build が失敗する。

- `/* ===== SWMD-UI:BEGIN ===== */` 〜 `:END`
  DOM層。入力を集めて `ENGINE.calcState()` に渡し、返り値だけを描画する。
  **この層に計算式を書いてはいけない。** 書いた分はテストの網から外れる。

単一HTMLのままである理由は、GitHub Pages にそのまま置ける／オフラインで動く／
施設の環境で外部通信を伴わないこと。ビルド成果物を配布物にしない。

## 使い方

```bash
npm install          # jsdom のみ（UIテストとダンプ生成に使う）
npm test             # engine 抜き出し → 不変条件14件＋UI5件
npm run explore      # ランダム10,000ケースの探索テスト
npm run dump         # review/screen-dump.txt を生成
npm run check        # test + explore
```

`npm run explore 50000 12345` のようにケース数とシードを指定できる。
違反が出た場合は、再現用の入力オブジェクトがそのまま標準エラーに出力される。

## 既知の限界

- 月例給は年収÷(12＋賞与月数)の単純換算。夜勤手当・時間外・通勤手当を分離できない
- 非正規の賞与月数・事業主負担率を正規と同率で計算している（入力簡素化のため）
- 処遇改善加算を収益・人件費から分離していない（決算書からは切り分けられないため）
- 常勤換算数と実人数は別。シフト成立性・夜勤体制・有給取得は判定していない
